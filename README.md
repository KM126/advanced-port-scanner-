this is an advanced port scanner for local networks that can perform scans at lightning speed
the KM option will list all exploitable ports 

to install :
-1 clone this repo with the following command :
git clone https://github.com/KM126/advanced-port-scanner-
-2 install requirements :
gem install colorize && gem install socket 
-3 finnaly give exeutable permission and run the script :
chmod +x scan-ports.rb 
ruby scan-ports.rb
